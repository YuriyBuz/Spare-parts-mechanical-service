# Бекенд Apps Script — інструкція зі встановлення

## Файли

| Файл | Що робити |
|---|---|
| `Code.gs` | **Замінити цілком** вміст вашого поточного `Code.gs` |
| `Penalties.gs` | **Не чіпати** — лишається як є |

## Кроки

1. Відкрити проєкт Apps Script → файл `Code.gs`.
2. `Ctrl+A` → вставити вміст `Code.gs` із цієї теки.
3. **Розгортання → Керувати розгортаннями → олівець → Версія: НОВА ВЕРСІЯ → Розгорнути.**
   URL веб-застосунку не зміниться, фронтенд правити не треба.
4. Запустити з редактора один раз: **`fixCredentialColumnsToText()`**.
5. Запустити **`auditCredentialZeros()`** — у журналі виконання буде список
   працівників, чий логін/пароль уже втратив нуль. Ці рядки перевписати вручну
   в таблиці (після кроку 4 нуль збережеться).
6. Рекомендовано: **Тригери → Додати тригер → `cleanupOldSessions` → раз на день.**

## Перевірка після встановлення

- Працівник із логіном-телефоном, що починається з `0`, має входити.
- Пароль `09` має прийматися.
- Схвалення відпустки на кілька днів має зафарбувати **весь період** у графіку.
- Спроба працівника (не адміна) викликати `get_employees_list` має повертати
  «Недостатньо прав».
