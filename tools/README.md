# Генератори довідників

`apps-script/Seed.gs` і `config/checklist-config.json` не пишуться руками — вони
збираються з двох джерел:

1. `checklistConfig` у клієнті `YuriyBuz/mechanic-checklist` → 43 пункти механіка;
2. історія звітів із таблиці `check-list-mechanic` → чек-лист майстра (30 пунктів,
   фронтенду немає в git), виведені з ужитку пункти та історичні написання варіантів.

## Порядок

```bash
python3 tools/parse_raw.py    # вигрузка таблиці → answers.json (12 615 відповідей)
python3 tools/gen_seed.py     # answers.json + index.html клієнта → Seed.gs, config json
```

Шляхи до вхідних файлів задані константами вгорі кожного скрипта — виправте під себе.
`parse_raw.py` очікує текстову вигрузку таблиці; переноси рядків у ній відновлюються
за емодзі-маркерами, бо експорт Drive їх схлопує.

## Що можна правити руками

Нічого в `Seed.gs`. Правки робіть у самій таблиці — аркуші `01_Пункти` і
`02_Варіанти`. `seedDictionaries()` оновлює рядки за ключем і **не видаляє** те,
чого немає в Seed, тож ваші правки переживуть повторний запуск.

Виняток — рішення, зашиті в `gen_seed.py`: `OVERRIDE` (зміна типу пункту),
`NORMS` (чернетка норм), `STATUS_FIX` (виправлені статуси варіантів),
`LEGACY_STATUS`, `MASTER` (відновлений чек-лист майстра). Їх правити тут.
